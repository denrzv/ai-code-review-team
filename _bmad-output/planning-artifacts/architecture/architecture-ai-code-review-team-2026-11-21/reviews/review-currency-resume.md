# Currency and reality check after resume

**Verdict** Conditional pass. The SDK release, retention model and DeepSeek request shape support the architecture. Pin the dev runtime, specify the SDK cancellation policy, and make the artifact publication primitive explicit before handoff. Compile and wire tests remain implementation acceptance criteria.

## Findings

1. **High · Atomic report publication needs a guaranteed no-replace primitive (AD-13).** Java 25 `Files.move` with `ATOMIC_MOVE` ignores other options and can replace an existing target depending on the filesystem provider. Select an atomic no-replace manifest publication on the supported local filesystem, such as linking a fully prepared immutable manifest with create-if-absent semantics. Verify support and exercise concurrent publication on the target filesystem. [Java 25 Files API](https://docs.oracle.com/en/java/javase/25/docs/api/java.base/java/nio/file/Files.html#move(java.nio.file.Path,java.nio.file.Path,java.nio.file.CopyOption...))
2. **High · Awaiting Activity cancellation requires the explicit Java SDK policy (AD-16).** The default is `TRY_CANCEL`. Require `WAIT_CANCELLATION_COMPLETED` and use the configured Activity timeout envelope as the fallback. Heartbeats carry cancellation and may be throttled, so test the bounded cancellation path with a blocked call. Keep the Update handler non-blocking and return the disposition promptly. If it blocks, finish accepted handlers before Workflow exit, using `Workflow.isEveryHandlerFinished`. [Activity execution](https://docs.temporal.io/develop/java/activities/execution) · [Heartbeats and throttling](https://docs.temporal.io/encyclopedia/detecting-activity-failures) · [Java message passing](https://docs.temporal.io/develop/java/workflows/message-passing)
3. **Medium · Pin the Temporal CLI dev server version.** The official CLI release lists 1.10.0 with embedded OSS Server 1.32.2. Record it in the stack and set namespace retention before the first run because retention changes only affect executions that close after the change. Workflow ID open conflict and closed reuse are separate policies. [Temporal CLI 1.10.0](https://github.com/temporalio/cli/releases/tag/v1.10.0) · [Temporal Java SDK 1.41.1](https://github.com/temporalio/sdk-java/releases/tag/v1.41.1) · [Retention](https://docs.temporal.io/temporal-service/temporal-server) · [Workflow ID rules](https://docs.temporal.io/workflow-execution/workflowid-runid)
4. **Medium · Capture actual DeepSeek wire behavior in the FEATURE-002 spike.** Official Chat Completions documents `deepseek-flash`, `thinking.type=disabled`, `max_tokens` and `response_format.type=json_object`. JSON mode needs a JSON instruction and can return blank content or truncate on the length limit. Confirm LangChain4j emits those wire fields, forwards no built-in tools and has zero automatic retries. Keep local validation and one repair. Strict tool-schema mode is a separate Beta capability. [Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/) · [Thinking mode](https://api-docs.deepseek.com/guides/thinking_mode/) · [JSON output](https://api-docs.deepseek.com/guides/json_mode/) · [Tool calls](https://api-docs.deepseek.com/guides/tool_calls/)
